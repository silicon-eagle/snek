# snek
This is a small side project to create a goofy pixelated snake game + an algorithm to always win or to play the game. It is written in typescript, react and vite + html canvas. 

The algorithm is a hamiltonian cycle, which is a cycle that visits every vertex of a graph exactly once. In this case, the graph is the grid of the game. The algorithm is implemented in a way that it can be used to play the game or to always win the game.

Besides the algorithm, there is also a simple implementation of the game itself, which can be played by the user by simply pressing one of the arrow keys or buttons to 'take control' of the snake. The game is designed to be simple and fun, with a pixelated art style and a catchy soundtrack.

The main idea is to incorporate this project in a larger website, so it is built modular.
